# Technical Task

In **TypeScript or Python**, build a script that accepts a cryptocurrency wallet address and outputs a CSV containing:

* The wallet address
* The wallet balance
* Up to four additional columns you believe would be valuable when screening an address

## Requirements

* You are free to choose the cryptocurrency and data sources.
* You may use external libraries and APIs.
* Using AI or similar tools is expected. However, please avoid submitting a large amount of generated code that you cannot explain, as we will ask detailed questions during the interview that you will need to defend.
* We prefer a small, clear submission over unnecessary features.
